# Fonts

Self-hosted fonts available to AR Studio builds.

| Font | Files | Licence |
| --- | --- | --- |
| Chaumont Script (ANRT, Alexandre Bassi, Chantal Jacquet, Timothée Gouraud) | `chaumont-script/` (woff2, woff) | SIL Open Font License 1.1 |

Use it with:

```css
@font-face{font-family:"Chaumont Script";src:url("fonts/chaumont-script/ChaumontScript-Regular.woff2") format("woff2"),url("fonts/chaumont-script/ChaumontScript-Regular.woff") format("woff");font-display:swap}
```

IM Fell English (headers) and Bricolage Grotesque (body) load from Google Fonts.
