# AR Studio

Art shop and laptop fund site. Single-page, no build step: `index.html` is the whole site
(images and the Sketch Studio engine are embedded), deployed on Vercel from `main`.

- `index.html` — the site. Edit the block marked `Edit these` near the top of the script to change
  the goal, amount raised, price, gallery items, plans and slideshow.
- `sketch-studio-engine.js` — the standalone Sketch Studio engine (drawing cleanup and mockups), for reuse.
